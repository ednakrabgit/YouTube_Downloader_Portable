# 🎥 YouTube Downloader Portable (MP4 / MP3)

โปรแกรมดาวน์โหลดวิดีโอและเสียงจาก YouTube แบบพกพา (**Portable .EXE**) ใช้งานง่าย ไม่ต้องติดตั้งโปรแกรมหรือ Python บนเครื่อง

---

## ✨ คุณสมบัติเด่น (Features)
- 🎬 **เลือกรูปแบบไฟล์ได้ 3 แบบ**:
  - **MP4**: ดาวน์โหลดวิดีโอความคมชัดสูงสุด (รวมภาพและเสียงชัดเต็มความละเอียด)
  - **MP3**: แยกและแปลงเฉพาะไฟล์เสียงความละเอียดสูง (192 kbps)
  - **ทั้ง 2 แบบ (MP4 + MP3)**: โหลดทั้งวิดีโอและแปลงไฟล์เสียงพร้อมกันในครั้งเดียว
- 🔗 **ดาวน์โหลดหลายลิงก์พร้อมกัน (Batch Download)**: วางลิงก์ทีละกี่รายการก็ได้ (บรรทัดละ 1 ลิงก์) หรือลิงก์ Playlist
- 📂 **กำหนดโฟลเดอร์ปลายทางได้**: เลือกโฟลเดอร์ที่จะบันทึกไฟล์ได้อิสระ พร้อมปุ่มเปิดโฟลเดอร์เมื่อเสร็จ
- 📊 **แสดงสถานะแบบเรียลไทม์**: แสดง Progress Bar เปอร์เซ็นต์ ความเร็วในการดาวน์โหลด และบันทึก Logs
- ⚡ **Multi-Threading**: หน้าต่างโปรแกรมลื่นไหล ไม่ค้าง (Not Responding) ขณะดาวน์โหลดไฟล์ใหญ่
- 📦 **Standalone Portable**: รวม `yt-dlp` และ `FFmpeg 7.1` ไว้ในตัว ไม่ต้องติดตั้งอะไรเพิ่ม

## 🚀 วิธีการใช้งาน

### วิธีที่ 1: ใช้งานผ่านไฟล์ `.exe` ทันที
1. ดาวน์โหลดหรือเปิดไฟล์ `YouTube_Downloader_Portable.exe`
2. เลือกรูปแบบที่ต้องการ (**MP4**, **MP3** หรือ **ทั้ง 2 แบบ**)
3. วางลิงก์ YouTube ที่ต้องการดาวน์โหลดในกล่องข้อความ
4. เลือกโฟลเดอร์ปลายทาง (ค่าเริ่มต้นคือโฟลเดอร์ *Downloads*)
5. กดปุ่ม **"🚀 เริ่มดาวน์โหลดทั้งหมด (Start Download)"**

---

### วิธีที่ 2: รันจากโค้ดต้นฉบับ (Source Code)
1. ติดตั้ง Python (แนะนำเวอร์ชัน 3.10 ขึ้นไป)
2. ติดตั้ง Library ที่จำเป็น:
   ```bash
   pip install -r requirements.txt
   ```
3. รันโปรแกรม:
   ```bash
   python app.py
   ```

---

## 🛠 วิธีการคอมไพล์เป็น .EXE ใหม่ (Build Instructions)
หากต้องการแก้ไขโค้ดหรือคอมไพล์เป็นไฟล์ `.exe` ใหม่:
1. ดับเบิลคลิกที่ไฟล์ `build.bat` หรือรันผ่าน Command Line:
   ```cmd
   build.bat
   ```
2. สคริปต์จะดาวน์โหลด `ffmpeg.exe` (หากไม่มี) และทำการแพ็กไฟล์ด้วย PyInstaller
3. ไฟล์ที่ได้จะอยู่ในโฟลเดอร์ `dist\YouTube_Downloader_Portable.exe`
