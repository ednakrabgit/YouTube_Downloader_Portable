# 🎥 YouTube Downloader Portable (MP4 / MP3)

โปรแกรมดาวน์โหลดวิดีโอและเสียงจาก YouTube แบบพกพา (**Portable .EXE**) ใช้งานง่าย ไม่ต้องติดตั้งโปรแกรมหรือ Python บนเครื่อง

---

## ✨ คุณสมบัติเด่น (Features)
- 🎬 **เลือกรูปแบบไฟล์ได้ 3 แบบ**:
  - **MP4**: ดาวน์โหลดวิดีโอความคมชัดสูงสุด
  - **MP3**: แยกและแปลงเฉพาะไฟล์เสียงความละเอียดสูง (192 kbps)
  - **ทั้ง 2 แบบ (MP4 + MP3)**: โหลดทั้งวิดีโอและแปลงไฟล์เสียงพร้อมกันในครั้งเดียว
- 🍏 **รองรับ iPad mini 1 และอุปกรณ์รุ่นเก่า (Apple A5 / iOS 9)**:
  - บังคับการเข้ารหัสเป็น **H.264 (High Profile 4.1) / yuv420p / <=30fps / AAC / FastStart**
  - แก้ปัญหาเปิดเล่นใน iPad mini 1 / TV รุ่นเก่าแล้ว **จอดำ หรือ ได้ยินแต่เสียงไม่มีภาพ**
- 🛠 **ปุ่มซ่อม/แปลงไฟล์เดิม**:
  - มีปุ่ม `🍏 ซ่อมไฟล์ MP4 เดิมให้เล่นบน iPad ได้` ภายในโปรแกรม
  - มีสคริปต์ `convert_for_ipad.bat` สำหรับลากไฟล์ .mp4 มาวางเพื่อแปลงไฟล์ได้ทันที
- 🔗 **ดาวน์โหลดหลายลิงก์พร้อมกัน (Batch Download)**: วางลิงก์ทีละกี่รายการก็ได้ (บรรทัดละ 1 ลิงก์) หรือลิงก์ Playlist
- 📂 **กำหนดโฟลเดอร์ปลายทางได้**: เลือกโฟลเดอร์ที่จะบันทึกไฟล์ได้อิสระ พร้อมปุ่มเปิดโฟลเดอร์เมื่อเสร็จ
- 📊 **แสดงสถานะแบบเรียลไทม์**: แสดง Progress Bar เปอร์เซ็นต์ ความเร็วในการดาวน์โหลด และบันทึก Logs
- ⚡ **Multi-Threading**: หน้าต่างโปรแกรมลื่นไหล ไม่ค้าง (Not Responding) ขณะดาวน์โหลดไฟล์ใหญ่
- 📦 **Standalone Portable**: รวม `yt-dlp` และ `FFmpeg 7.1` ไว้ในตัว ไม่ต้องติดตั้งอะไรเพิ่ม

## 🚀 วิธีการใช้งาน

### 1. ใช้งานผ่านไฟล์ `.exe` ทันที
1. เปิดไฟล์ `YouTube_Downloader_Portable.exe`
2. เลือกรูปแบบที่ต้องการ (**MP4**, **MP3** หรือ **ทั้ง 2 แบบ**)
3. ติ๊กถูกช่อง `🍏 โหมดรองรับ iPad mini 1 / อุปกรณ์รุ่นเก่า` (เปิดไว้เป็นค่าเริ่มต้น)
4. วางลิงก์ YouTube ที่ต้องการดาวน์โหลดในกล่องข้อความ
5. กดปุ่ม **"🚀 เริ่มดาวน์โหลดทั้งหมด (Start Download)"**

### 2. ซ่อมไฟล์ MP4 ที่เคยดาวน์โหลดมาแล้ว ให้เปิดบน iPad mini 1 ได้
- **วิธี A**: เปิดโปรแกรมแล้วคลิกปุ่ม **"🍏 ซ่อมไฟล์ MP4 เดิมให้เล่นบน iPad ได้"** แล้วเลือกไฟล์วิดีโอเดิม
- **วิธี B**: ลากไฟล์ `.mp4` ไปวางบนไฟล์ **`convert_for_ipad.bat`** (Drag & Drop) จะได้ไฟล์ใหม่ลงท้ายด้วย `_ipad.mp4`

## 🛠 วิธีการคอมไพล์เป็น .EXE ใหม่ (Build Instructions)
1. ดับเบิลคลิกที่ไฟล์ `build.bat` หรือรัน:
   ```cmd
   build.bat
   ```
2. ไฟล์ที่ได้จะอยู่ใน `dist\YouTube_Downloader_Portable.exe`
